# Phase 6: Response Letter

## Status: NOT STARTED (do last)

### Format
Point-by-point response letter in LaTeX. For each reviewer comment:
1. Quote the reviewer's comment (in italics)
2. Provide our response
3. Reference specific manuscript changes (with line numbers or section references)
4. Reference new figures if applicable

### Template Structure
```
Dear Editor,

We thank the reviewers for their constructive feedback...

## Reviewer 1
### Comment 1 (Absolute density)
*"Could absolute density differences..."*

**Response:** We thank the reviewer for this important suggestion. We analyzed...
[Reference to new Supplementary Figure X]

### Comment 2 (pH × Dominance)
...
```

### Key Principles
- Be respectful and appreciative
- Address every point, even minor ones
- Show we did the work (reference specific new figures/analyses)
- Be honest when a concern partially applies
- Distinguish between changes we made vs explanations of why something is already addressed
