## Boundary Statements

The response must not claim that pairwise selection correlation uniquely identifies direct ecological interactions. The manuscript source explicitly frames community-level selection as outcome-level, mechanism-agnostic origin-correlated persistence.

The response must not claim that pairwise invasion assays fully predict multi-species coalescence. The response states that pairwise assays approximate two-species invasion fitness, whereas coalescence measures correlated multi-species invasion outcomes.

The local figure uses an independent-invasion null with the observed success probability. The manuscript Supplementary Fig. 28 caption describes an origin-shuffled null. The response letter should cite the manuscript figure and Supplementary Note for the submitted claim; the local figure is supporting audit material and reproduces the same reported Pearson trend.
