# Revision Submission Local Preparation

This folder contains local materials that can be prepared before logging into the Nature Ecology & Evolution submission portal.

It does not duplicate the main manuscript, Supplementary Information, or response letter. Those remain in their original `latex/` locations.

## Contents

- `reporting_summary/`
  - official blank Nature Reporting Summary PDF template
  - draft notes to help fill the form
- `source_data/`
  - source-data manifest mapping manuscript figures to likely local data files
  - draft README for eventual source-data workbook/ZIP
- `data_code_availability/`
  - current manuscript data/code availability statements
  - final items that still need accession, DOI, or portal confirmation

## Active Minimal PDF Folder

The active minimal folder is:

`../revision_sumission/`

It currently contains:

- revision cover letter PDF
- blank Reporting Summary PDF template marked `NEEDS_COMPLETION`

Do not add manuscript, Supplementary Information, response letter, or figure PDFs there unless the portal specifically asks for duplicate uploads.
