The Supplementary Methods are provided first. The Supplementary Notes are organized by topic. Supplementary Note 1 defines outcome classification, metric sensitivity, and null models. Supplementary Note 2 addresses assembly history and parental-affiliation-correlated species fates. Supplementary Note 3 tests simulation sensitivity to model assumptions. Supplementary Note 4 examines nutrient perturbation and pairwise invasion resistance. Supplementary Note 5 evaluates alternative mechanisms and controls. Supplementary Note 6 discusses natural sample-derived communities and stabilization caveats.

\rev{The main evidence trail is: Supplementary Note 1 is supported by Extended Data Figs.~2--3 and Supplementary Figs.~10--12, 37, and 44. Supplementary Note 2 is supported by Extended Data Figs.~5--6, 8 and Supplementary Figs.~3, 23, 32, and 36. Supplementary Note 3 is supported by Extended Data Fig.~4 and Supplementary Figs.~4--6 and 39--42. Supplementary Note 4 is supported by Supplementary Figs.~7--9. Supplementary Note 5 is supported by Extended Data Fig.~7 and Supplementary Figs.~13--16, 38, 43, and 45--46. Supplementary Note 6 is supported by Supplementary Figs.~19--22.}
