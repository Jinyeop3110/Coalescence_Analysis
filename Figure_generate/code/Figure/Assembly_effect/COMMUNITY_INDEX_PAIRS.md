# Assembly Effect Community Index Pairs

## Overview

This document lists all community index pairs used in the assembly effect analysis.

**Concept:**
- **Parent (Direct Assembly)**: Communities assembled directly from the full species pool
- **Coalesced (Coalescence)**: Communities formed by coalescing two smaller subcommunities
- **Sub1/Sub2**: The two parent communities that were mixed to create the coalesced community

**Comparison Question**: Does assembly pathway (coalescence vs. direct assembly) affect final community composition?

# Each pair contains:
# - parent_community_idx
# - coalesced_community_idx

# - sub2_community_idx
# - parent_sample, coalesced_sample, sub1_sample, sub2_sample
# - parent_abundances, coalesced_abundances, sub1_abundances, sub2_abundances
